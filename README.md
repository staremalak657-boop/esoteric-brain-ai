# 🛸 PROJECT_SHADOW_BRAIN: Hybrid Local AI

An experimental, 100% offline project that builds a local Sentiment Analysis AI in **Python** and compiles its core output logic into **Brainfuck**—one of the hardest esoteric programming languages in history.

---

## 🚀 Project Overview (النظرة العامة)

This project consists of three core components working entirely local:
1. **`offline_ai.py`**: A local NLP classifier analyzing user sentiments.
2. **`transpiler.py`**: A custom compiler that translates text into Brainfuck cells (`+`, `-`, `.`).
3. **`run_bf.py`**: A simulated virtual memory interpreter that executes the esoteric code.

---

## 🛸 Quick Start (دليل التشغيل)

```bash
python transpiler.py
python run_bf.py
